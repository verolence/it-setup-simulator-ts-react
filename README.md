# it-setup-simulator-ts-react
🎮 IT Setup Simulator — мини-игра на Node.js (Express, TypeScript) и React, где нужно собрать рабочее место в рамках бюджета. 

## Стек технологий
Frontend: React + TypeScript + Parcel 2
Backend: Node.js + Express + TypeScript
Dev: concurrently для одновременного запуска фронта и бэка
Дополнительно: CORS для работы фронта с бэком

## Запуск backend и frontend через concurrently
```
git clone <URL_репозитория>
cd it-setup-simulator-ts-react
npm install
npm run dev
```
В браузере открой http://localhost:1234 и играй!
