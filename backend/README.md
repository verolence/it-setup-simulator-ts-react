## Основные файлы backend-части проекта

📌 package.json →  «паспорт» проекта: что за проект, какие зависимости нужны, какие есть скрипты.

📌 tsconfig.json → настройки для компилятора TypeScript (как он будет переводить .ts → .js).

📌 src/index.ts → поднимает сервер и подключает маршруты

📌 src/routes/budget.ts → отдельный роут, который отдаёт бюджет

## Запуск backend изолировано от frontend:
Запускаешь npm run dev (сервер стартует).
В браузере открываешь http://localhost:3000/budget
Получаешь JSON, например: { "budget": 1700 }
